# Evidence — Bob IDE Session Screenshots

This directory stores Bob IDE task session screenshots required by the IBM Bob Hackathon.

## How to capture screenshots

The IBM Bob IDE does not expose a headless screenshot API, so screenshots must be
captured manually by the developer. Please capture and save the following sessions:

| File to save                  | What to capture                                                          |
|-------------------------------|--------------------------------------------------------------------------|
| `01_project_scaffold.png`     | Bob Agent session showing the scaffolding of the project structure       |
| `02_analysis_engine.png`      | Bob Agent session showing the creation of `analyzer/rules.py` and `analyzer/engine.py` |
| `03_tests_passing.png`        | Bob Agent session showing `pytest` run with all tests passing            |
| `04_demo_dirty_results.png`   | Browser screenshot of the UI after loading Demo 1 (dirty diff) and clicking Analyze |
| `05_demo_clean_results.png`   | Browser screenshot of the UI after loading Demo 2 (clean diff) and clicking Analyze |
| `06_readme_complete.png`      | Bob Agent session showing the completed README                           |

## Naming convention

Use the filenames above exactly. PNG format preferred; JPEG acceptable.

## Notes

- Do **not** include any real credentials, customer data, or personal information in screenshots.
- Crop or blur any sensitive IDE settings visible in the screenshot.
- Screenshots are stored here for hackathon evidence only and are not part of the application.
